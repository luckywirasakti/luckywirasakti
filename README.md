## 🚀 Engineering Highlights

- **Scaled backends to millions of requests/day** — architected and operated the backend for an internal enterprise field operations platform serving a nationwide FMCG distributor with sub-100ms response times.
- **High-throughput ETL & reconciliation** — engineered nightly cron pipelines and asynchronous export jobs synchronizing tens of thousands of records across distributed enterprise services with zero manual overhead.
- **Distributed 50,000 vouchers with zero double-redemption** — built a high-concurrency campaign delivery system over official WhatsApp Business API with pessimistic locking and explicit transaction isolation.
- **Fraud-resistant payment disbursement** — developed a Midtrans Iris payout service enforcing one-claim-per-verified-phone with row locking and request throttling to prevent abuse.
- **Database & Query Optimization** — resolved query bottlenecks on Microsoft SQL Server, PostgreSQL, and MySQL through advanced indexing, query restructuring, and connection tuning for enterprise CRMs.
- **LLMs & RAG in production** — integrated LLMs into automated content generators and engineered RAG chatbots with persistent vector memory for continuous context learning.
- **Integration middleware** — built an OAuth2 webhook-routing layer sustaining high-volume partner calls with automatic retries for guaranteed zero data loss.
- **Automated CI/CD & Delivery** — wired Dokploy staging previews and self-hosted GitLab runners into CI/CD for fully automated, hands-off deployments.
